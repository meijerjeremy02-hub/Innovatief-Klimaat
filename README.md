### Beschrijving van het project

Innovatief Klimaat is een website voor docenten en docententeams waarmee ze kunnen meten hoe het klimaat binnen hun team is. De website werkt met een vragenlijst die dient als gespreksstarter binnen het team. Deze README beschrijft de front-end van het hele project. De API wordt tegelijkertijd door mij apart ontwikkeld. Wat ik in de eerste week (sprint) aan de front-end maak, staat in `README1.md`.

**Wat de front-end nu heeft:**

- Een vragenlijst die de antwoorden lokaal opslaat.
- Een resultatenscherm dat werkt, maar nu nog dummydata laat zien.
- Een adminpagina waarop een teamcode gegenereerd kan worden en waarop de resultaten bekeken kunnen worden (voor nu ook met dummydata).
- De mogelijkheid om een college aan een team toe te voegen.
- Een mobiele en een desktoplayout voor alle pagina's.

**Wat er nog gedaan moet worden:**

- Gebruikers zien alleen hun eigen resultaten en de resultaten van hun team.
- De admin kan filteren op college en kan individuele vragen binnen een dimensie van teams inzien.
- De adminpagina aanpassen en beveiligen met een wachtwoord.
- De front-end voorbereiden op de API, zodat de dummydata later eenvoudig vervangen kan worden door echte data.
- De front-end koppelen aan de API zodra die klaar is.
- De website online zetten met de front-end en de API aan elkaar gekoppeld.

### Reden(en) voor dit project

- Docententeams krijgen inzicht in hoe het teamklimaat ervaren wordt.
- De vragenlijst helpt om het gesprek binnen het team op gang te brengen.
- Ik leer een complete webapplicatie te bouwen, van ontwerp tot een koppeling met een API.
- Ik leer een gebruiksvriendelijke interface te maken die op zowel mobiel als desktop goed werkt.

### Randvoorwaarden

- **AVG:** De vragenlijst bevat gevoelige informatie over hoe mensen het teamklimaat ervaren. De front-end slaat daarom zo min mogelijk persoonsgegevens op. Gebruikers zien alleen hun eigen resultaten en die van hun team, en de adminpagina wordt met een wachtwoord beveiligd. Lokaal opgeslagen antwoorden worden alleen gebruikt voor de werking van de vragenlijst.
- **Copyright en licenties:** Gebruikte libraries, lettertypen, iconen en afbeeldingen moeten een licentie hebben die gebruik toestaat. Bronnen worden vermeld waar dat nodig is.
- **Wettelijke impact:** Naast de AVG moet de website toegankelijk zijn. Daarom let ik op voldoende kleurcontrast, een duidelijke structuur en bruikbaarheid op verschillende schermformaten.
- **Maatschappelijke impact:** De uitkomsten kunnen gevoelig liggen binnen een team. Resultaten worden daarom zorgvuldig en neutraal getoond, en zijn bedoeld als startpunt voor een gesprek, niet als beoordeling van personen.
